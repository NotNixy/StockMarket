#
# Exact pins looked more rigorous and were worse: they forced pip to BUILD
# pandas from source on a Python version the pinned release has no wheel for,
# which needs a C++ toolchain and fails. Floors let pip pick a release that
# ships a wheel for whatever Python you have.
#

#     .venv\Scripts\python.exe -m pip freeze > requirements.lock.txt
# That file records the exact set, without making the install brittle.
